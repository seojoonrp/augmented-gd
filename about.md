# Augmented GD

**Turn any level into a roguelite run.** Die, draft an augment, get stronger, and keep going until you beat it.

## How an augmented run works

1. Open any online level and press the round button next to the difficulty face. The run starts with a free draft.
2. Every death charges the **draft gauge** at the bottom of the screen by the percent you reached. Beating your best for the run pays the new percents twice.
3. When the gauge is full, you draft as you respawn: pick one of three augments. Picking one you already have levels it up.
4. Keep repeating, claim augments, clear the level and the run is won.

## Augments

There are 13 augments, each with different maximum levels.

You can check the detailed augment informations [here](https://docs.google.com/spreadsheets/d/1_z0HGqntrP07kUEpNs5o8UhFGAX475KxqDkIrGYIanA/edit?usp=sharing).

## Controls

- **X**: toggle Sloth
- **Z**: place a checkpoint
- **C** (hold): brake

All three can be rebound in the mod's settings.

## Disclaimer

Augmented runs never count as real progress. A run attempt does not save a normal-mode percent or show GD's New Best!, and clearing a run is not counted as a level completion. The mod keeps its own record for each level instead.

## Notices

- Supports only English and Korean for now.
- Windows only for now. Updates will be done soon!
- Platformer levels work, but classic levels are recommended.
