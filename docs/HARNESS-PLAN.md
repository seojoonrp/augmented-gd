# Harness plan — reference corpus for AI agents

Goal: an agent working on this mod can find *how a working Geode 5 / GD 2.2081
mod does X* in one or two commands, instead of guessing GD internals.
Started 2026-09-16. Tick items as they land; record the date.

## Diagnosis (2026-09-16)

- Good skeleton already: CLAUDE.md rules, `GD-INTERNALS.md` lookup table, `refs/`.
- `refs/openhack` targets GD 2.206 / Geode 3.4 (last commit 2024-10) — stale,
  its byte-patch offsets are a trap. Replace.
- `refs/` has no index: every question means grepping ~180 files.
- Lookup procedures exist only as prose (`awk '/^class PlayLayer /…'`).
- Installed mods (QOLMod, click_between_frames, custom-keybinds, death_tracker…)
  are undocumented, yet they both interfere with hooks and are reference material.
- `$GEODE_SDK/AGENTS.md` states the Geode index does not accept AI-written mods.
  Irrelevant for private testing; noted in DESIGN.md under "before public release".

## Phase 0 — reference corpus (`scripts/fetch-refs.ps1`)

Only repos targeting GD 2.2081 / Geode 5.x, pinned to a commit.

| repo | why | covers |
|---|---|---|
| `TheSillyDoggo/QOLMod` | installed by user, open source, Geode 5 | hitboxes, noclip, speedhack, key input, label HUD |
| `Zilko/xdBot` | macro bot | checkpoints/frame step, PlayLayer lifecycle, slow-mo |
| `geode-sdk/docs` | official tutorials (markdown, small) | modify, events, settings, keybinds, Popup, layout |
| `geode-sdk/NodeIDs` | source instead of dll grep | node IDs per layer |
| `geode-sdk/DevTools` | node tree inspector | UI debugging |
| `geode-sdk/example-mod` | minimal template | style baseline |
| `Cvolton/betterinfo-geode` | large; LevelInfoLayer buttons/popups | UI patterns |
| keep `custom-keybinds`, `miscbugfixes` | | |
| Eclipse Menu (OpenHack successor) | repo name to verify | replaces openhack |
| drop `openhack` | version mismatch | keep a summary of its hitbox patch in docs only |

Also: installed mods with public source (`syzzi.click_between_frames` — hooks
Windows input directly, `elohmrow.death_tracker`).
Output: `refs/MANIFEST.md` (repo, pinned commit, date, geode/gd target, license,
one-line purpose), generated by the script.

## Phase 1 — lookup scripts

- `scripts/bro.ps1 <Class> [member]` — class block from bindings, flags `win inline` / missing address.
- `scripts/refgrep.ps1 <pattern> [-Sdk] [-Bindings]` — one rg over `refs/`, `$GEODE_SDK/loader`, bindings; build output excluded.
- `scripts/nodeids.ps1 <Layer>` — node IDs for a layer from the NodeIDs source.
- `scripts/mods.ps1` — installed mods + versions (interference analysis, STATUS).

## Phase 2 — analysis → problem-first index (main deliverable)

Per ref: `docs/refs/<name>.md` — overview, versions, `$modify` targets,
**feature → file:line**, patterns worth copying, traps.
Then `docs/refs/INDEX.md` keyed by *problem*:
hitboxes / key input / speedhack-time scale / noclip / checkpoints-startpos /
pause menu / LevelInfoLayer buttons / HUD labels / settings / popups / events /
hook priority vs other mods → ref file:line + where our code does it.
Fixed procedure per ref (mod.json → CMake → `$modify` grep → feature map) so
adding a ref later is mechanical.

## Phase 3 — fold into existing docs

- `GD-INTERNALS.md`: verified facts from Phase 2, especially **key input**
  (the path QOLMod / CBF / CustomKeybinds really use on Geode 5), checkpoints
  (xdBot), installed-mod interference table.
- `docs/RECIPES.md`: verified snippets in this project's style (Fields hook,
  event listener, setting read, popup, node-ids button, CCDrawNode, scheduler
  hook, FMOD pitch). Each marked "verified <date>" or "(from ref X, unverified here)".
- `CLAUDE.md`: add `docs/refs/INDEX.md` to the reading order, one line per script. Keep it short.
- `DESIGN.md`: one line on the Geode index AI policy.

## Phase 4 — acceptance test

Solve the open **hotkey bug** using only the new harness (INDEX → refgrep →
bro.ps1). Every place the harness fails to answer is a harness defect: fix it.
Hotkey log line appears in game → harness passes.

## Rules

- Licenses are mixed (GPL/MIT); MANIFEST records them. Copy *patterns*, not code.
- `refs/` stays gitignored; only `docs/refs/*` is committed, so a fresh
  session can read the index without cloning.
